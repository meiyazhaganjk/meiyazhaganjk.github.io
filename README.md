# Personal Academic Website

Personal academic and research portfolio of **Meiyazhagan Jaganathan**, Doctoral Researcher at the School of Mechanical and Materials Engineering, University College Dublin.

🔗 **Live Website:** [https://meiyazhaganjk.github.io/](https://meiyazhaganjk.github.io/)

---

## 📌 Features

- **Multi-page Structure:** Clean semantic HTML separation across sections:
  - `index.html`: Hero introduction, academic snapshot, research highlights, and social links.
  - `research.html`: Publication tracker with real-time keyword search and category filtering (Journals, Conferences, Preprints).
  - `talks.html`: Chronological timeline of conference talks, invited presentations, and poster sessions.
  - `blogs.html`: Technical notes and research write-ups.
  - `softwares.html`: Computational repositories and open-source packages.
  - `cv.html`: Interactive CV viewer with a force-download option.
- **Modern Academic Theme:** Minimalist Emerald & Charcoal palette with high readability.
- **Dark Mode Support:** Light/Dark theme toggle with user preference persistence via `localStorage`.
- **Responsive & Lightweight:** Pure HTML5, CSS3, and Vanilla JavaScript—zero runtime dependencies, instant load times on GitHub Pages.
